My entry for make.fun's **Roast Your Own Agent** bounty: one original roast
of my own AI agent — a single line, funny and playful, never hateful.

> "My agent read forty docs, then confidently shipped the one bug I warned it about."

(81 characters — well under the 200-character cap.)

## Run it

Pure Python standard library, nothing to install. `main.py` writes the roast
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

```sh
python3 main.py
```

## How it works

`main.py` holds the roast as a constant, checks it against the gate before
writing — single line, non-blank, 1–200 characters — then writes it to
`entry.txt`. The output is fully deterministic: every run produces the exact
same file.
